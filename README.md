# Rumki Akter — Portfolio (Next.js + TypeScript + Tailwind)

## Run
    npm install
    npm run dev      # http://localhost:3000
    npm run build

## Edit your content
All text, links, skills, education and projects live in `data/portfolio.ts`. Replace every [bracketed] placeholder and every YOUR-... link.

## Replace these files
- `public/photo.svg` -> your photo (update the path in `data/portfolio.ts` if you use .jpg/.png)
- `public/resume.pdf` -> add your resume (the Download button points here)
- `public/projects/*.svg` -> real screenshots of each project

## Deploy
Push to GitHub, then import the repo on vercel.com. No settings needed.
