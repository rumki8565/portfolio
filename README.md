# Rumki Akter — Portfolio

A responsive personal portfolio website built with Next.js, TypeScript and Tailwind CSS.

**Live site:** https://portfolio-pi-seven-0jesa3kjie.vercel.app

## Features

- Responsive navbar with a mobile menu and active section highlighting
- Hero section with my designation, photo, resume download button and social links
- About me section covering my journey, the work I enjoy and my hobbies
- Skills section with progress bars, grouped into Frontend, Tools and Backend
- Projects section with cards and a detailed page for each project, showing the tech stack, description, live link, GitHub repository, challenges and future plans
- Contact section with email and phone
- Light and dark theme that follows the device setting
- Fully responsive on mobile, tablet, laptop and desktop

## Projects shown

- BookNook: online library app (Next.js, BetterAuth, Express, MongoDB, JWT)
- BazarDor: grocery price website with a Bengali interface (Next.js, Tailwind CSS, BetterAuth)
- FitLog: gym workout library (Next.js, Tailwind CSS)
- Dev Stack: tech stack picker (React, TypeScript)

## Tech stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- lucide-react (icons)
- Deployed on Vercel

## Run locally

```bash
git clone https://github.com/rumki8565/portfolio.git
cd portfolio
npm install
npm run dev
```

Then open http://localhost:3000.

## Customise the content

All personal details, skills and projects are in `data/portfolio.ts`. Images and the resume are in the `public` folder.
